Formula / confidence notes

Working reverse-engineering model: Coverage = sum(best) / 60 × 100, where best is the higher value from the two drivers for each of the six stats. Balance = 100 × (1 − population SD(best) / 3), floored at 0. Overlap = sum(|A − B|) / 60 × 100. Synergy = 0.845 × (balance + overlap) − 10.7, clamped to 0–100. This reproduces the observed synergy values 11, 31 and 67 for the test cases in the reverse-engineering notes. Overlap is still not fully confirmed because the observed game value of 24 for pair 2 rounds differently from this simple model's 23.

Known checks: Pair 3 → Coverage 85, Balance 14, Overlap 12, Synergy 11. Pair 2 → Coverage 90, Balance 25, Overlap 23 by the simple overlap formula, Synergy 31. The game's recorded Pair 2 overlap was 24, so that one component remains a reverse-engineering target.
